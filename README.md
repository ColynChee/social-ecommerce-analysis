# 社交电商用户行为分析 - 交互式可视化

## 项目概述

这是一个基于100K条社交电商用户行为数据的交互式可视化系统，旨在帮助理解用户分群特征、消费行为与商品偏好的关系。系统提供三个主要分析视角：数据总览、年龄分群、行为洞察。

## 核心功能

### 1. 数据总览（Overview）

展示全量用户的整体特征：

- **消费金额分布**（柱状图 + 密度曲线）
  - 显示21个消费区间：0-500, 501-1000, ..., 9501-10000, 10001-15000, ..., 50000+
  - 非展开状态：显示0-9501-10000，高消费区间合并为"10000+"
  - 展开状态：显示完整的所有区间
  - **交互**：点击任意柱子查看该消费区间最受欢迎的商品类别Top5

- **性别分布**（饼图）
  - 男性 vs 女性用户占比

- **社交散点图**
  - X轴：社交活跃度（粉丝数 + 关注数）
  - Y轴：消费金额
  - **交互**：展示社交活跃度与消费金额的关系

- **顶级商品类别**（词云）
  - 展示购买最频繁的商品类别

### 2. 年龄分群（Age Groups）

按年龄段分别展示用户特征：

- **年龄段选择**：18-25, 26-35, 36-45, 46+
- **展示内容**：
  - 该年龄段的用户数、平均消费、平均购买频率、性别比例
  - 消费金额分布（同样支持展开查看详细区间）
  - 性别分布、社交散点图、顶级商品类别

### 3. 行为洞察（Behavior Insights）

多维度用户行为分析：

- **筛选维度**：
  - 年龄段：全部、18-25、26-35、36-45、46+
  - 性别：全部、男性、女性
  - 用户等级：全部、1级、2级、...（动态从数据中获取，当前为1-7级）

- **可视化图表**：
  - **社交购买桑基图**：展示社交活跃度 → 购买行为的流向
  - **行为漏斗图**：展示用户从浏览到购买的转化漏斗

- **社交互动与购买关系分析**
  - 分析点赞数、评论数、分享数、互动率和购买意向在不同分组下的购买率差异
  - 支持通过下拉菜单切换分析指标：点赞数、评论数、分享数、互动率、购买意向
  - 使用相关性矩阵展示浏览、点赞、评论、分享、收藏、加购、用券、购买意向和最终购买之间的相关关系
  - **分析目标**：判断点赞、评论、分享等“种草行为”是否直接促进购买，以及哪些行为更接近真实购买意图

- **用户行为路径分析**
  - 构建“浏览 → 社交互动 → 加购物车 → 领券 → 用券 → 购买”的行为路径
  - 使用路径流向图展示用户在不同行为阶段之间的流动
  - 使用路径排行榜展示最常见的行为路径、路径人数和购买率
  - **分析目标**：识别用户从浏览到购买的典型转化路径，并发现主要流失环节

## 设计决策

### 可视化编码

1. **消费金额分布 - 柱状图**
   - X轴：消费区间 - 展示消费水平分布
   - Y轴：用户数 - 反映各区间用户规模
   - 密度曲线：展示分布趋势
   - **为什么**：柱状图适合展示分类数据的频率分布，密度曲线补充趋势信息

2. **社交散点图**
   - X轴：社交活跃度（粉丝数 + 关注数）- 用户社交影响力
   - Y轴：消费金额 - 用户价值
   - **为什么**：散点图直观展示社交活跃度与消费金额的关系，便于发现用户群体聚类

3. **桑基图 & 漏斗图**
   - 展示用户行为流向和转化
   - **为什么**：直观展示用户从社交活跃到购买的转化过程

4. **社交互动分组购买率 - 条形图**
   - X轴：不同互动水平分组，如点赞数、评论数、分享数、互动率
   - Y轴：购买率
   - **为什么**：条形图适合比较不同分组之间的购买率差异，能够直观展示高互动用户是否具有更高购买倾向。

5. **互动行为相关性矩阵 - 热力图**
   - 行列变量：浏览次数、点赞数、评论数、分享数、收藏数、加购、用券、购买意向、最终购买
   - 颜色深浅：相关系数强弱
   - **为什么**：相关性矩阵适合展示多个行为变量之间的整体关系，帮助判断社交互动、加购、用券等行为与最终购买之间的关联程度。

6. **用户行为路径图**
   - 节点：浏览、社交互动、加购物车、领券、用券、购买、未购买等行为阶段
   - 连线宽度：经过该路径的用户记录数量
   - **为什么**：路径图能够将用户行为串联起来，展示从兴趣产生到最终购买的过程，比单独的统计图更能体现转化链路。

### 交互设计

- **点击柱子查看详情**：展示该消费区间最受欢迎的商品类别Top5
- **展开/收起**：消费分布支持展开查看完整区间
- **多维筛选**：行为洞察支持按年龄、性别、等级组合筛选
- **Tab切换**：在三个主要视角间快速切换
- **深色/浅色模式**：支持主题切换
- **互动指标切换**：在社交互动分析中，可切换点赞数、评论数、分享数、互动率和购买意向，观察不同互动指标下的购买率变化
- **相关性热力矩阵**：通过颜色深浅展示不同用户行为指标之间的相关性，支持快速识别与购买更相关的行为
- **行为路径排行榜**：展示最常见的用户行为路径，并对比不同路径下的购买率

## 技术栈

- **前端框架**：Vue 3（组件化、响应式）
- **可视化库**：D3.js 7（灵活的图形绘制、交互），并结合原生 SVG、HTML/CSS 实现自定义路径图、条形图和相关性矩阵
- **构建工具**：Vite（快速开发和构建）
- **数据处理**：Python + Pandas（数据聚合和统计）

## 数据处理流程

1. **原始数据加载**：`data/social_ecommerce_data.csv`

2. **基础数据聚合**：
   - 按用户聚合：计算每个用户的消费金额、购买频率、社交活跃度等
   - 按消费区间聚合：统计各区间的用户数和商品类别分布
   - 按年龄段聚合：分别统计各年龄段的用户特征

3. **行为洞察数据生成**：
   - 计算点赞、评论、分享等社交互动行为与购买率之间的关系
   - 按点赞数、评论数、分享数、互动率和购买意向进行分组，统计每组的购买率、加购率、用券率和样本数
   - 计算浏览、点赞、评论、分享、收藏、加购、用券、购买意向和最终购买之间的相关性矩阵

4. **行为路径数据生成**：
   - 根据每条记录判断是否发生浏览、社交互动、加购物车、领券、用券和购买
   - 构建用户行为路径，例如“浏览 → 社交互动 → 加购物车 → 购买”
   - 统计各路径的人数和购买率
   - 生成路径流向图和路径排行榜所需的数据结构

5. **结果输出**：`analysis_results.json` 和 `public/data/analysis_results.json`

6. **前端展示**：Vue组件从JSON中读取数据并渲染

## 关键实现细节

### 消费分布的智能展示
- **非展开状态**：将10001元及以上的所有区间合并为"10000+"，保持图表简洁
- **展开状态**：显示完整的21个区间，支持细粒度分析
- **动态计算**：根据实际数据动态生成区间，确保数据准确性

### 商品类别Top5
- **统计方式**：按消费区间统计该区间内用户购买最频繁的5个商品类别
- **展示内容**：类别名称 + 购买次数
- **交互方式**：点击柱子弹出tooltip显示

### 用户等级的动态获取
- **之前**：硬编码1-10级
- **现在**：从数据中动态获取实际存在的等级（1-7级）
- **优势**：数据和UI保持同步，避免显示不存在的等级

### 社交互动与购买关系分析

该模块重点分析点赞、评论、分享等社交电商中的“种草行为”是否与购买行为存在关联。系统将点赞数、评论数、分享数、互动率和购买意向分别进行分组，并计算每组的购买率。用户可以通过下拉菜单切换不同互动指标，观察不同互动水平下的购买率变化。

同时，系统使用相关性矩阵展示浏览次数、点赞数、评论数、分享数、收藏数、加购、用券、购买意向和最终购买之间的相关关系。分析结果可以帮助判断哪些行为更接近用户真实购买意图。

### 用户行为路径分析

该模块将用户行为抽象为“浏览 → 社交互动 → 加购物车 → 领券 → 用券 → 购买”的转化过程，并进一步区分未互动、未加购、未购买等流失路径。系统通过路径流向图展示用户在不同行为阶段之间的流动，并通过路径排行榜展示最常见的用户行为路径及其购买率。

该模块用于回答“用户从浏览到购买通常经历哪些行为阶段”以及“哪些路径更容易转化”这两个问题。

npm run build
