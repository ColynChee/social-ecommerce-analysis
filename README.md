# 社交电商用户行为分析 - 交互式可视化

## 项目概述

这是一个基于100K条社交电商用户行为数据的交互式可视化系统，旨在帮助理解用户分群特征、消费行为与商品偏好的关系。系统提供三个主要分析视角：数据总览、年龄分群、行为洞察。

## 核心功能

### 1. 数据总览（Overview）

展示全量用户的整体特征：

- **消费金额分布**（柱状图 + 密度曲线）
  - 显示21个消费区间：0-500, 501-1000, ..., 9501-10000, 10001-15000, ..., 50000+
  - 非展开状态：显示0-9501-10000，高消费区间合并为"10000+"
  - 展开状态：显示完整的所有区间
  - **交互**：点击任意柱子查看该消费区间最受欢迎的商品类别Top5

- **性别分布**（饼图）
  - 男性 vs 女性用户占比

- **社交散点图**
  - X轴：社交活跃度（粉丝数 + 关注数）
  - Y轴：消费金额
  - **交互**：展示社交活跃度与消费金额的关系

- **顶级商品类别**（词云）
  - 展示购买最频繁的商品类别

### 2. 年龄分群（Age Groups）

按年龄段分别展示用户特征：

- **年龄段选择**：18-25, 26-35, 36-45, 46+
- **展示内容**：
  - 该年龄段的用户数、平均消费、平均购买频率、性别比例
  - 消费金额分布（同样支持展开查看详细区间）
  - 性别分布、社交散点图、顶级商品类别

### 3. 行为洞察（Behavior Insights）

多维度用户行为分析：

- **筛选维度**：
  - 年龄段：全部、18-25、26-35、36-45、46+
  - 性别：全部、男性、女性
  - 用户等级：全部、1级、2级、...（动态从数据中获取，当前为1-7级）

- **可视化图表**：
  - **社交购买桑基图**：展示社交活跃度 → 购买行为的流向
  - **行为漏斗图**：展示用户从浏览到购买的转化漏斗

## 设计决策

### 可视化编码

1. **消费金额分布 - 柱状图**
   - X轴：消费区间 - 展示消费水平分布
   - Y轴：用户数 - 反映各区间用户规模
   - 密度曲线：展示分布趋势
   - **为什么**：柱状图适合展示分类数据的频率分布，密度曲线补充趋势信息

2. **社交散点图**
   - X轴：社交活跃度（粉丝数 + 关注数）- 用户社交影响力
   - Y轴：消费金额 - 用户价值
   - **为什么**：散点图直观展示社交活跃度与消费金额的关系，便于发现用户群体聚类

3. **桑基图 & 漏斗图**
   - 展示用户行为流向和转化
   - **为什么**：直观展示用户从社交活跃到购买的转化过程

### 交互设计

- **点击柱子查看详情**：展示该消费区间最受欢迎的商品类别Top5
- **展开/收起**：消费分布支持展开查看完整区间
- **多维筛选**：行为洞察支持按年龄、性别、等级组合筛选
- **Tab切换**：在三个主要视角间快速切换
- **深色/浅色模式**：支持主题切换

## 数据处理流程

1. **原始数据加载**：`data/social_ecommerce_data.csv`
2. **数据聚合**：
   - 按用户聚合：计算每个用户的消费金额、购买频率、社交活跃度等
   - 按消费区间聚合：统计各区间的用户数和商品类别分布
   - 按年龄段聚合：分别统计各年龄段的用户特征
3. **结果输出**：`public/data/analysis_results.json`
4. **前端展示**：Vue组件从JSON中读取数据并渲染

## 关键实现细节

### 消费分布的智能展示
- **非展开状态**：将10001元及以上的所有区间合并为"10000+"，保持图表简洁
- **展开状态**：显示完整的21个区间，支持细粒度分析
- **动态计算**：根据实际数据动态生成区间，确保数据准确性

### 商品类别Top5
- **统计方式**：按消费区间统计该区间内用户购买最频繁的5个商品类别
- **展示内容**：类别名称 + 购买次数
- **交互方式**：点击柱子弹出tooltip显示

### 用户等级的动态获取
- **之前**：硬编码1-10级
- **现在**：从数据中动态获取实际存在的等级（1-7级）
- **优势**：数据和UI保持同步，避免显示不存在的等级
