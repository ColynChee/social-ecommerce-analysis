# 社交电商用户行为分析 - 交互式可视化

## 项目概述

这是一个基于100K条社交电商用户行为数据的交互式可视化系统，旨在帮助理解用户分群特征与商品内容特征对购买行为的影响。

## 核心问题

**主要问题**：社交电商平台中，不同用户群体有什么特征差异？商品的哪些内容属性最能驱动购买？

**关键洞见**：
- 4个明显的用户群体：高频购买者、普通用户、社交达人、VIP用户
- 折扣率10-20%时购买率最高（51.7%），比无折扣提升21%
- 图片数量7+张时互动率最高（18.55%）

## 设计决策

### 可视化编码

1. **用户分群散点图**（主视图）
   - X轴：消费金额 - 直观展示用户价值
   - Y轴：购买频率 - 反映用户活跃度
   - 气泡大小：社交活跃度 - 编码第三维度
   - 颜色：群体标签 - 快速识别群体

   **为什么选择散点图**：能同时展示3个连续变量，支持群体聚类的视觉识别

2. **群体特征雷达图**（详情视图）
   - 5个维度：消费金额、购买频率、社交活跃度、年龄、购买率
   - 标准化到0-1范围便于对比

   **为什么选择雷达图**：多维度对比时直观，能快速看出群体的强弱项

3. **内容特征柱状图**（分析视图）
   - 折扣率分组 vs 购买率
   - 图片数量分组 vs 互动率
   - 关键发现用红色高亮

   **为什么选择柱状图**：分类数据对比最清晰，易于识别最优值

### 交互设计

- **点击散点图群体** → 联动更新雷达图和柱状图
- **Tab切换** → 在折扣率和图片数量间切换
- **Hover工具提示** → 显示具体数值

**设计理由**：支持用户围绕"选定群体"进行深度探索，形成完整的分析流程

### 替代方案考虑

| 方案 | 优点 | 缺点 | 最终决策 |
|------|------|------|---------|
| 散点图 | 展示3维数据，支持聚类识别 | 需要理解气泡大小编码 | ✓ 采用 |
| 平行坐标图 | 展示多维数据 | 复杂度高，交互困难 | ✗ 放弃 |
| 雷达图 | 多维对比直观 | 不适合展示原始数据 | ✓ 采用 |
| 柱状图 | 分类对比清晰 | 只能展示2维 | ✓ 采用 |

## 数据源

- **原始数据**：`data/social_ecommerce_data.csv`（100,000条记录）
- **处理方式**：
  - 按用户聚合：计算每个用户的消费金额、购买频率、社交活跃度
  - K-means聚类：k=4，基于标准化的3个特征
  - 内容特征分析：按折扣率、图片数量分组统计购买率

- **聚合数据**：
  - `data/user_clusters.csv`：用户分群结果
  - `data/analysis_results.json`：分析统计结果

## 技术栈

- **前端框架**：Vue 3（组件化、响应式）
- **可视化库**：D3.js 7（灵活的图形绘制）
- **构建工具**：Vite（快速开发和构建）
- **部署**：GitHub Pages（静态托管）

**技术选择理由**：
- Vue 3提供清晰的组件结构，便于多人协作
- D3.js提供完全的可视化控制，支持复杂交互
- Vite提供快速的开发体验
- GitHub Pages无需服务器，数据直接从静态文件加载

## 项目结构

```
src/
├── main.js              # Vue应用入口
├── App.vue              # 根组件，整合三个视图
└── components/
    ├── ClusterScatter.vue    # 散点图组件
    ├── ClusterDetail.vue     # 雷达图组件
    └── ContentFeature.vue    # 柱状图组件
data/
├── user_clusters.csv         # 用户分群数据
└── analysis_results.json     # 分析结果
```

## 开发过程

### 时间投入（预计）
- 数据分析：4小时
- 前端开发：8小时
  - ClusterScatter.vue：2.5小时
  - ClusterDetail.vue：2.5小时
  - ContentFeature.vue：2小时
  - App.vue整合：1小时

- **人员1**：ClusterScatter.vue（散点图 + 交互逻辑）

- **人员3**：ContentFeature.vue（柱状图）+ 部署配置

### 开发亮点
1. **多视图协调**：点击散点图自动更新其他两个视图

4. **响应式布局**：支持不同屏幕尺寸
